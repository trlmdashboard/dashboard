Website / API Load Tester

Manual load, or automatic step-ramp to find the concurrency level where errors start.

Only test URLs you own or have explicit written permission to test — including your own Apps Script web app deployments. Firing high-volume requests at anything else is indistinguishable from a denial-of-service attack and may be illegal. Limits below are capped intentionally: there is no "unlimited" mode, because a page that fires unbounded requests is a DoS tool, not a test tool.

If this is cross-origin and doesn't send CORS headers, browsers will block reading the status code — you'll still see timing, but errors may show as generic network failures.

Each stage fires "requests per stage" total calls at that stage's concurrency, measures the error rate, then moves to the next stage. The test stops automatically once error rate crosses your threshold, concurrency hits the max, or the time cap is reached — whichever comes first.
